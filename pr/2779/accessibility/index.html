Overview

Background

Captions, subtitles, and accessibility technologies enable the representation of spoken dialogue, non-speech information, and alternative language or sensory experiences for audiences with diverse needs. Across theatrical, broadcast, and online workflows, these systems encompass timed text formats, rendering and styling models, signaling mechanisms, and interchange practices designed to support comprehension, localization, and accessibility compliance. In practice, accessibility solutions span authoring, packaging, distribution, and playback, integrating with media formats and delivery ecosystems to ensure consistent, interoperable presentation across platforms and devices.

This specification defines WebVTT, the Web Video Text Tracks format. Its main use is for marking up external text track resources in connection with the HTML <track> element. WebVTT files provide captions or subtitles for video content, and also text video descriptions [MAUR],…This specification defines WebVTT, the Web Video Text Tracks format. Its main use is for marking up external text track resources in connection with the HTML <track> element. WebVTT files provide captions or subtitles for video content, and also text video descriptions [MAUR], chapters for content navigation, and more generally any form of metadata that is time-aligned with audio or video content.

This specification is based on the Draft Community Group Report of the Web Media Text Tracks Community Group.
