  • API Explorer — search & browse the registry

  • api/doc/<docId>.json — per-doc record with full $meta provenance
  • api/search/index.json — compact search shards (current editions), sized for AI fetch tools
  • api/by-publisher.json — full-record slices per publisher and doc type
  • api/groups.json — groups registry
  • api/projects.json — projects registry
  • api/by-doc.json — docId → owning groups and projects
  • api/publishers.json — publishers, logos, doc counts
  • api/vocabulary.json — keywords, doc types, content types
  • api/mri-cite-map.json — MRI inline-citation sidecar (refs known to MRI, no registry doc)
  • api/stats.json — registry statistics & metadata
  • api/schemas/documents.schema.json — JSON Schema for documents (others in api/schemas/)
