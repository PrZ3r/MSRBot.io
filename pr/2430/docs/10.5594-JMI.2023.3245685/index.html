Machine Learning Applied to Media Libraries for Insights, Search, and Segmentation

Abbreviated Title
SMPTE Mot. Imag. J
Volume
132, No. 3, pp. 27–38
Abstract
Recent advances in machine learning (ML) have produced a new form of semantic indexing that lets users enhance searches and gain new insights into their media libraries. Unlike typical search systems that use extracted metadata, semantic indexing allows users to find relevant material without the need to tag the media with selections from a predefined taxonomy. With semantic search, users can simply enter unstructured text, and the system will find the best matching media clips. This article extends the use of this technology to gather analytics on the data, which can then be further correlated to generate various insights. This new form of media indexing can be performed with the contrastive language-image pretraining (CLIP) model from OpenAI for images and similar models for video and audio. These models encode media into embeddings that can be searched to find the closest semantic similarity, enhanced with learned cultural knowledge. These systems have the benefit of finding media based on keywords, synonyms, and summaries. The systems can also be used for analytics and insights, such as segmentation, shot detection, and creating a 2D map to display correlations. This article ends with a discussion of the next steps, including using knowledge graphs for semantic search.

Conclusion Semantic indexing is a new method of searching for and retrieving media files that uses ML to extract and encode semantic representations found in various media formats. This allows for searches using unstructured text queries, which can be faster and more accurate than traditional metadata searches. Semantic representations can also be used to provide insights into the media library. The CLIP model from OpenAI is one example of a model that can be used for semantic indexing, and the Elasticsearch database can be used to store the resulting embeddings. There are many potential applications for semantic search, including finding media with queries that contain summaries or synonyms, using learned cultural knowledge. Additionally, semantic search can be extended to use multiple languages for queries and used to find additional media types like video clips and audio files. Next Steps Recently, the EBU, Movie labs, and SMPTE published a primer29 on using semantic technologies, which, among the various uses, lists contextual search and discovery as one of the benefits. The approach outlined in that primer discusses using a knowledge graph of triples stored in graph databases to relate semantically linked data. This approach is an alternate, if not complementary, approach to semantic search using embeddings. Prior to the primer mentioned earlier, Wei et al.30 provided a comprehensive overview of semantic search systems based on linked data. Semantically linked systems provide for usage that can go beyond conventional search usage. The entity-relationship graph lends itself to queries that go beyond resolving a search query to a digital asset. The entity relationships can be used to discover hitherto unknown relationships between data records and digital assets by traversing edges in the graph to provide insights and recommendations;31 to organize the data in predefined structures, making traversal and automation possible; to connect heterogeneous and distributed data sources while maintaining data integrity. Most of these knowledge graph-based systems require standardized predefined ontologies and a-priori-defined taxonomies to model the relationships. In contrast, text embedding-based systems can discover the taxonomy. Next steps include comparing the architectures and results of using semantic embeddings versus this new approach to knowledge graphs for searching media libraries. Part of the investigation is to evaluate if the technologies complement each other rather than being distinct approaches. EXTERNAL
