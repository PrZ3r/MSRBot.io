The fundamental assumption of the SDT framework is normal probability distributions for the signal and errors.38 Therefore, a mapping function that better reflects the real distribution of each quality factor should lead to more accurate user models. A third important limitation was the small participant sample. Adding more participants would increase the opportunity of collecting representative data, and the larger sample size would increase the power of statistical analysis and the developed prediction models. Future research could include a fine-tuning stage where active learning algorithms are employed.56,57 Active learning will allow the system to learn directly from humans by querying the caption quality. The selection algorithm would prioritize caption variations that had greater uncertainty associated with them, providing a more efficient training process. Conclusion In this paper, the design and development of a novel system to assess the quality of CC based on caption viewer subjective quality ratings is described. Based on findings from a user study with hearing-impaired viewers, a set of human decision probability models dealing with captioning variations was developed. With these user models and prediction models, we then generated artificial data, which reflected human assessment of caption quality. We then trained deep neural networks with the generated data, creating an AI system to predict human subjective ratings for different caption variations. The proposed solution fills a gap in existing quality assessment models for CC, which does not include any viewer quality assessment factors. The proposed system should improve as more data are collected, allowing the core prediction model to learn from the new user data over time.EXTERNAL
